BLUSH ESTATE

An evening arrival, in rose gold.

The Rolls Royce waits at the foot of the manor, chrome catching the last light of dusk.

Built entirely in HTML & CSS

This page doesn't load any outside image files — the mansion and the pink Rolls Royce are hand-drawn using inline SVG shapes (rectangles, polygons, paths, and circles) styled with CSS variables for the color palette. That makes it a great file to open in VS Code and experiment with: try changing the values under :root to shift the whole mood of the scene, or nudge the numbers inside the <svg> block to reshape the car and building.

Things to try next

Change --car-pink to a different hex code and watch the car repaint itself instantly. Try adjusting the viewBox numbers on the <svg> element to zoom in or out of the scene. You can also swap this hand-drawn illustration for a real photo later by replacing the whole <svg> block with an <img src="your-photo.jpg"> tag once you have an image file saved in your project folder.

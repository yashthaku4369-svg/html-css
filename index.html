Can you show me how to build a clean ChatGPT UI in HTML and CSS?

Absolutely! A modern ChatGPT interface incorporates three primary design pillars:

  1. Dark theme color palette: Neutral grays like #212121 and deep dark #171717 for the sidebar.
  2. Floating input bar: A rounded container with attachment options, voice controls, and an intuitive send trigger.
  3. Responsive layout: A collapsible sidebar paired with a flexible main viewport.

Here is an example snippet showing how the floating prompt bar is structured in HTML:

html 
<div class="input-container">
  <button class="icon-btn">+</button>
  <textarea placeholder="Message ChatGPT..."></textarea>
  <button class="send-btn">▲</button>
</div>
